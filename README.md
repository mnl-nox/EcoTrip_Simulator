# EcoTrip

Simule e compare o impacto ambiental de diferentes meios de transporte.

## Prévia

[Abrir EcoTrip no GitHub Pages](https://mnl-nox.github.io/EcoTrip_Simulator/)

## Executar localmente

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Sobre os cálculos

Os fatores de emissão são estimativas ilustrativas. Consulte o [modelo e suas premissas](doc/modelo.md) antes de usar os valores em relatórios.
